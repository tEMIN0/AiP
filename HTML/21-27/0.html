Что представляет собой CMS

CMS - "система управления контентом" (движок) - базовая структура для сайта, созданная PHP-разработчиками, с помощью которой можно управлять сайтом (добавлять материалы, редактировать меню и т.д.) без знаний HTML и CSS.

Но для создания сайта на CMS потребуются услуги программиста, дизайнера и верстальщика. Плюс финансовые вложения.

Какие существуют CMS

Существуют разные системы управления контентом: для магазинов в интернете, блогов, форумов и прочее.

Примеры CMS

Примеры известных CMS: Joomla, WordPress (для блогов), PhpBB (для форумов).

CMS-системы бывают платными и бесплатными.

PHP и JavaScript

Языки программирования PHP и JavaScript дают возможность сделать сайт динамичным, то есть откликающимся на действия пользователя. К примеру, можно создать эффектное выпадающее меню или слайдер.

Виды скриптов

Для этого создаются скрипты (англ. script - "сценарий") - программы, реагирующие на действия пользователя. Скрипты делятся на два вида:

  • те, которые запускаются на сервере, а их результат приходит в браузер пользователя в готовом виде. Это скрипты на языке PHP. На нем создаются CMS-ки – системы управления контентом.
  • те, которые выполняются непосредственно в браузере пользователя. Это скрипты на языке JavaScript. Они обычно применяются, чтобы сделать страницу удобнее и привлекательнее.
